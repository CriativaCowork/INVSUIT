Como Utilizar o Simulador

1. O que é o Tempo para Dobrar o Patrimônio?

Este simulador calcula quanto tempo leva para o seu patrimônio duplicar através do efeito dos juros compostos. É uma ferramenta essencial para planear a sua independência financeira, permitindo-lhe visualizar o poder do tempo e dos juros a seu favor.

2. A Regra de 72

A Regra de 72 é uma fórmula simplificada: divida 72 pela taxa de juros anual para obter uma estimativa rápida do tempo para dobrar. Ex.: com 12% ao ano, 72 ÷ 12 = 6 anos. É uma aproximação útil mas o simulador calcula o valor exato.

3. Capitalização Composta

A frequência de capitalização afeta o resultado. Quanto mais frequente (mensal, diária ou contínua), mais rápido o crescimento. Capitalização contínua é o cenário matemático ideal usando a fórmula e^(rt).

4. Aportes Mensais

Adicionar aportes regulares acelera significativamente o crescimento do patrimônio. Mesmo valores modestos têm impacto enorme a longo prazo graças ao efeito bola de neve dos juros compostos.

5. Impacto da Inflação

A inflação corrói o poder de compra. Use o campo de inflação para ver o valor real do seu patrimônio. A taxa real de retorno = taxa nominal - inflação (aproximação). Para países da CPLP, este fator é crucial.

6. Melhores Práticas

• Compare diferentes cenários usando a funcionalidade de guardar cenários
• Use taxas de juros realistas para o seu país/mercado
• Considere sempre a inflação para ter uma visão realista
• Aumente aportes gradualmente conforme a sua renda cresce
• Utilize o conversor de moedas para comparar em diferentes divisas da CPLP
• Exporte relatórios PDF para acompanhar a evolução dos seus planos

7. Cenários e Templates

Na aba Cenários pode guardar, editar, clonar e filtrar simulações. Os templates pré-definidos ajudam a compreender diferentes perfis de investimento: conservador, moderado e agressivo.

8. Exportação e Partilha

Exporte os seus dados em JSON para backup ou partilha, gere imagens HD dos gráficos, ou crie relatórios PDF profissionais. Use o botão de importação para restaurar dados guardados anteriormente.
