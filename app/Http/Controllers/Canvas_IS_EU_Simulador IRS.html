Como Utilizar

1. Preencha os seus dados

No separador Simulador, insira o seu rendimento bruto anual, outros rendimentos, deduções e retenções mensais. Os cálculos atualizam em tempo real.

2. Analise os resultados

Visite o separador Resultados para ver gráficos detalhados da distribuição dos seus rendimentos, impostos por escalão e deduções aplicadas.

3. Compare cenários

Guarde diferentes simulações para comparar cenários. Pode clonar, editar ou criar cenários do zero. Use templates de aprendizagem para explorar casos comuns.

4. Câmbio CPLP

Converta valores entre moedas da CPLP. Edite as taxas de câmbio manualmente para refletir valores atuais.

5. Exportações

Exporte os seus dados em JSON (para backup/importação), imagem HD ou PDF profissional com cabeçalho e paginação.

Melhores Práticas

• Organize deduções: Guarde todos os comprovativos de despesas de saúde, educação e habitação.

• Simule antes de declarar: Use o simulador para prever o imposto antes da entrega oficial.

• Compare cenários: Simule diferentes valores para otimizar a sua declaração.

• Atualize câmbio: Se recebe rendimentos noutras moedas CPLP, mantenha as taxas atualizadas.

• Exporte regularmente: Faça backup dos seus cenários em JSON para não perder dados.

• Consulte um profissional: Este simulador é uma ferramenta indicativa. Consulte um contabilista para a declaração oficial.

Sobre a Importância

O Imposto sobre o Rendimento das Pessoas Singulares (IRS/IRPF/IRT) é uma das principais fontes de receita dos Estados e incide diretamente sobre os rendimentos dos cidadãos.

Compreender como funciona o sistema de escalões, deduções e retenções na fonte é essencial para uma boa gestão financeira pessoal e para evitar surpresas na altura da liquidação.

Nos países da CPLP, cada nação tem o seu próprio regime fiscal, mas os princípios base são semelhantes: tributação progressiva, deduções por despesas e dependentes, e retenção na fonte ao longo do ano.
