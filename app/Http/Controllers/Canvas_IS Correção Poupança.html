O que é este Simulador

O IS Correção Poupança permite calcular a correção de um valor monetário com base numa taxa de poupança ao longo de um período histórico. É útil para compreender o impacto dos juros compostos sobre valores investidos ou poupados no passado, utilizando o Kwanza (AOA) como moeda base e com conversões para moedas dos países da CPLP.

Como Utilizar

1. No separador Simulador, insira o valor inicial, o período (ano início/fim) e a taxa de poupança anual.

2. Os resultados são calculados automaticamente com gráficos e tabela detalhada.

3. Atribua um título e clique em Guardar para salvar o cenário.

4. No separador Cenários, visualize, edite, clone ou elimine simulações guardadas.

5. No separador Moedas, ajuste as taxas de câmbio para conversões correctas.

6. Utilize os botões de exportação no cabeçalho para PDF, imagem ou JSON.

Melhores Práticas

✓ Compare cenários — guarde diferentes simulações com taxas variadas para analisar impactos.

✓ Atualize as taxas de câmbio — mantenha as taxas no separador Moedas atualizadas para conversões precisas.

✓ Exporte regularmente — use a exportação JSON para backup e partilha de dados.

✓ Use títulos descritivos — facilita a identificação dos cenários guardados.

✓ Analise a tabela anual — entenda como os juros compostos crescem ao longo do tempo.

Notas Importantes

⚠ Este simulador é uma ferramenta educativa e de planeamento. Os valores são estimativas baseadas em taxas fixas.

⚠ As taxas de poupança reais variam conforme a instituição bancária e o período.

⚠ As taxas de câmbio apresentadas são indicativas e devem ser actualizadas manualmente.

⚠ Não constitui aconselhamento financeiro profissional.
