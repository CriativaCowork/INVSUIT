Guia de Utilização

Aprenda a utilizar o IS Aquisição de forma eficiente

📋 Gestão de Pedidos

O módulo de pedidos permite registar todas as solicitações de compra da sua organização.

  • Registe novos pedidos com descrição, categoria, fornecedor e valor
  • Acompanhe o estado de cada pedido (pendente, aprovado, rejeitado)
  • Filtre pedidos por estado ou texto para encontrar rapidamente
  • Edite ou elimine pedidos conforme necessário

🏢 Gestão de Fornecedores

Mantenha uma base de dados organizada dos seus parceiros comerciais.

  • Registe informações de contacto e categoria de cada fornecedor
  • Classifique fornecedores por área de atuação
  • Aceda rapidamente aos dados quando criar novos pedidos

💰 Gestão de Orçamentos

Defina e controle os limites de gastos por categoria.

  • Estabeleça orçamentos por departamento ou categoria
  • Visualize o progresso de utilização em tempo real
  • Receba alertas visuais quando se aproximar dos limites

📊 Simulador de Compras

Projete cenários de aquisição antes de comprometer recursos.

  • Defina orçamento total, período e parâmetros económicos
  • Adicione itens para simular e veja o impacto em tempo real
  • Considere inflação e margem de segurança nos cálculos
  • Guarde cenários para comparação futura

💱 Taxas de Câmbio

Configure as taxas de conversão para moedas da CPLP e USD.

  • Moeda base: Kwanza Angolano (AOA)
  • Suporte para: Real (BRL), Escudo (CVE), Metical (MZN), Dobra (STN), Pataca (MOP), USD
  • Atualize as taxas manualmente conforme necessário

✅ Melhores Práticas

Organização

  • Mantenha os fornecedores atualizados
  • Categorize os pedidos corretamente
  • Defina orçamentos realistas

Simulações

  • Use templates como ponto de partida
  • Considere sempre a inflação
  • Guarde cenários para comparar

Backup

  • Exporte os dados regularmente
  • Mantenha cópias em JSON
  • Use a exportação PDF para relatórios

Moedas

  • Atualize as taxas frequentemente
  • Verifique antes de grandes compras
  • Use o gráfico para comparação
