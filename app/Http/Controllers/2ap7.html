ℹ️ Bem-vindo ao IS Inventory Pro

Sistema avançado de gestão multi-armazém com rastreamento completo de movimentações, datas editáveis e análise de margens de lucro.

✨ Funcionalidades Principais

  • ✓ Categorias Personalizadas - Crie e organize categorias de produtos
  • ✓ Armazém "Sede" Automático - Sistema cria armazém padrão. Adicione outros conforme necessário
  • ✓ Produtos Obrigam Armazém - Cada produto deve estar associado a um armazém (são físicos!)
  • ✓ Produtos com Margem - Defina margens em valor fixo (Kz) ou percentual (%)
  • ✓ Movimentações com Datas Editáveis - Data/hora automática por padrão, mas edite quando necessário
  • ✓ 6 Tipos de Movimentação - Entrada, Saída, Transferência, Expiração, Apreensão, Destruição
  • ✓ Preço de Venda Automático - Calcula preço com margem aplicada
  • ✓ Histórico Completo Editável - Todos os dados podem ser atualizados
  • ✓ Performance por Armazém - Análise de distribuição e requisições
  • ✓ Gráficos Dinâmicos - Visualização em tempo real

📖 Passo a Passo

1️⃣ Criar Categorias

Vá para "Categorias" e crie as categorias de produtos que irá usar

2️⃣ Armazéns Já Configurados

O sistema cria automaticamente o armazém "Sede". Adicione outros em "Armazéns" se precisar

3️⃣ Adicionar Produtos

Em "Inventário": selecione armazém (obrigatório), nome, SKU, quantidade, preço, categoria e margem

4️⃣ Registrar Movimentações

Em "Movimentações": escolha produto, armazém, tipo de movimento, quantidade. Data é automática (hoje), mas pode editar

5️⃣ Editar Dados

Clique em ✏️ para editar qualquer produto ou movimentação. Todos os dados são atualizáveis

6️⃣ Analisar e Guardar

Acompanhe em "Performance" e "Análises". Guarde cenários em "Cenários" para backup

💡 Dicas Importantes

  • • Armazém obrigatório - Produtos devem estar em um armazém (não são cloud!)
  • • Margem Fixa (Kz) - Use para produtos com lucro fixo por unidade
  • • Margem Percentual (%) - Use para aplicar margem proporcional ao preço
  • • Datas editáveis - Registre com data de hoje (automático), mas edite se necessário
  • • Editar tudo - Produtos, movimentações e categorias podem ser atualizados a qualquer momento
  • • Cenários como backup - Guarde snapshots do sistema em momentos importantes
  • • Exportar dados - Faça backup em JSON ou veja relatório em PDF
