Sobre o IS CalcFin

O IS CalcFin é uma calculadora visual de fita desenvolvida especificamente para o empreendedor. Inspirada no conceito da CalcTape, esta ferramenta oferece uma experiência de cálculo intuitiva com histórico visual completo.

🎯 Funcionalidades Principais

  • Calculadora de Fita: Visualize todos os cálculos como uma fita de máquina registadora
  • Percentagens Simples Corretas: Digite apenas "4%" ou "-4%" para calcular percentagens sobre o TOTAL ACUMULADO!
  • Percentagens com Operações: Use "2000+20%" para cálculos completos com valor mostrado em parênteses
  • Edição Completa: Clique em qualquer cálculo para editá-lo e os subtotais recalculam automaticamente
  • Inserir Cálculos em Qualquer Lugar: Setas laranja (↑) e azul (↓) em cada linha para inserir antes ou depois!
  • Comentários: Adicione descrições a cada cálculo para melhor localização e documentação
  • Subtotais em Qualquer Lugar: Insira subtotais em posições específicas da fita - não apenas no final!
  • Gráficos Interativos: Clique nas barras para navegar e editar cálculos
  • Múltiplas Moedas: Suporte para AOA, BRL, EUR, MZN, STN, CVE e USD
  • Cenários: Guarde, edite nomes e reutilize conjuntos de cálculos
  • Pesquisa: Filtre cálculos e cenários por palavras-chave
  • Modo Expandido: Visualize a fita em modo tabela com filtros, como Excel
  • Exemplos Práticos: Aprenda com casos reais de uso
  • Exportação: PDF e JSON para fita de cálculo e cenários

✨ Novidades Versão 2.8
