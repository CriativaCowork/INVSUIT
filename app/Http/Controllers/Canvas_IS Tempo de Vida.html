Como Usar

1. Introduza os seus dados

Preencha o seu rendimento mensal em Kwanzas e as horas de trabalho mensais. O simulador calcula automaticamente o valor da sua hora de trabalho.

2. Adicione itens ou despesas

Insira o nome e custo de cada item. Escolha a categoria e frequência. O sistema calcula quantas horas de vida cada compra representa.

3. Analise os gráficos

Os gráficos dinâmicos mostram a distribuição dos custos, comparação entre itens e o impacto acumulado no seu tempo de vida.

4. Guarde e compare cenários

Salve diferentes cenários para comparar decisões financeiras. Clone cenários existentes para testar variações.

5. Exporte os resultados

Exporte em PDF, imagem ou JSON. Use a importação para recuperar dados salvos anteriormente.

Importância

Quando pensamos no preço de algo, raramente pensamos em quanto tempo da nossa vida aquele item realmente custa. Este simulador transforma valores monetários em horas de trabalho, tornando as decisões financeiras mais tangíveis.

Ao visualizar o custo real em tempo, criamos uma consciência financeira mais profunda, ajudando a priorizar gastos e a construir o caminho para a independência financeira.

Melhores Práticas

  • Inclua todos os rendimentos no valor mensal para uma análise precisa
  • Considere custos recorrentes usando a opção de frequência adequada
  • Compare cenários diferentes antes de tomar decisões de compra importantes
  • Reveja os seus cenários mensalmente para ajustar hábitos de consumo
  • Use os templates de aprendizagem como ponto de partida para análises comuns
  • Mantenha as taxas de câmbio atualizadas para conversões precisas
  • Exporte regularmente os seus dados em JSON como cópia de segurança
