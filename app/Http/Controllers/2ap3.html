Guia de Utilização

Este gerador de gráficos permite criar visualizações profissionais de funil, treemap, hierarquia e pizza para análise de dados e apresentações.

🎯 Como Começar

  1. Selecione a aba do tipo de gráfico desejado
  2. Clique em "Novo" para criar um gráfico ou use um template
  3. Preencha os dados no formulário
  4. O gráfico é atualizado em tempo real
  5. Exporte como imagem, Excel ou PDF

📊 Tipos de Gráficos

  • Funil: Ideal para visualizar processos de conversão (vendas, marketing)
  • Funil Invertido: Para mostrar crescimento ou expansão progressiva
  • Treemap: Excelente para comparar proporções em hierarquias
  • Hierarquia: Perfeito para organogramas e estruturas
  • Pizza: Para distribuição percentual com valores reais

💡 Melhores Práticas

  • • Use títulos descritivos e claros
  • • Limite o número de segmentos para melhor legibilidade
  • • Escolha cores contrastantes
  • • Salve cenários para comparações futuras
  • • Use tags para organizar seus gráficos

💰 Moedas CPLP

O sistema usa Kwanza (AOA) como moeda padrão. No painel de moedas pode:

  • • Configurar taxas de câmbio para BRL, EUR, CVE, MZN, STN, USD
  • • Os valores são convertidos automaticamente

📁 Exportação e Importação

  • • JSON: Backup completo de todos os dados
  • • Imagem HD: Cada gráfico individualmente
  • • Excel: Dados em formato de tabela
  • • PDF: Documento profissional com todos os gráficos

Dica Pro

Use a funcionalidade de cenários para guardar diferentes versões dos seus dados. Isso permite comparar simulações e voltar a configurações anteriores facilmente!
