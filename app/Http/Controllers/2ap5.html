💡 Sobre o Simulador

Este simulador foi desenvolvido para ajudar você a entender e gerir melhor o seu dinheiro. Seja para uso pessoal ou empresarial, o controlo do fluxo de caixa é essencial para a saúde financeira.

💰 O que é Fluxo de Caixa?

O fluxo de caixa é o movimento de dinheiro que entra e sai das suas contas. Existem três tipos principais:

  • • Operacional: Relacionado às atividades principais (salário, vendas, contas fixas)
  • • Projetado: Estimativa futura (planeamento)
  • • Real: Registo do que realmente aconteceu

📊 Conceitos-Chave

VPL (Valor Presente Líquido)

Traz todos os fluxos de caixa futuros para o valor atual, considerando o "custo" do tempo (taxa de desconto).

VPL = Σ [FCt / (1 + i)t] - Investimento Inicial

✅ VPL > 0 = Projeto viável

TIR (Taxa Interna de Retorno)

É a taxa que faz o VPL ser igual a zero. Representa o retorno percentual do investimento.

✅ TIR > Taxa de desconto = Projeto atrativo

Payback

Tempo necessário para recuperar o investimento inicial através dos fluxos de caixa.

✅ Quanto menor, mais rápido o retorno

IL (Índice de Lucratividade)

Relação entre o valor presente dos fluxos e o investimento. Mostra quanto se ganha por cada unidade monetária investida.

IL = VP dos Fluxos / Investimento Inicial

✅ IL > 1 = Lucro para cada unidade investida

ROI (Retorno sobre Investimento)

Percentual de retorno em relação ao investimento inicial.

ROI = [(Ganho - Investimento) / Investimento] × 100
